# D455深度与手眼标定排查（2026-10-18）

## 当前结论

深度没有明显的厘米级随机抖动，但不能因此认定其绝对测距准确。使用用户提供并声明方格32mm的ChArUco板作不含手眼外参的对照，原始深度比RGB几何预测的板面Z大约12.3mm。它表明RGB/板尺寸/深度这一内部几何链存在约1.9%的尺度差异，尚不能唯一认定为深度传感器硬件偏差。用户随后明确说明223mm读数存在测量误差，确认继续按224mm总宽、32mm方格处理。223mm等比例复算不作为本次结论依据，也未应用于任何运行参数。

此外，当前D455手眼候选原有留出验证误差中位11.78mm、最大15.30mm。该验证使用RGB标定板位姿和机械臂位姿，不使用深度图；因此该项误差不能归咎于深度读数。它反映的是整条手眼标定/采样链路的一致性，不代表每个抓取点都具有相同方向的恒定偏移。

## 标定板独立对照

完全在相机坐标系计算：ChArUco32mm方格 + 当前彩色K/D → solvePnP/RefineLM → 板平面；按去畸变后的各像素射线求预测光轴Z，再与同位置原始对齐深度比较。没有调用手眼外参或机器人坐标。

- 10帧，每帧20～22个ChArUco角点、15～16个标记。
- 重投影RMS约0.287～0.397px，方格约19.4px。
- 所用RGB和深度时间戳一致。
- RGB板面Z中位约0.633m，原始深度约0.645m。
- 同像素“深度减RGB板平面预测Z”的帧中位数总体中位12.324mm，各帧11.521～12.459mm。
- 折算尺度差约1.946%。按用户确认的224mm设计尺寸保留原始12.324mm对照结果，不采用223mm缩放。此差异尚不能唯一归因为深度传感器硬件偏差。

该对照不是绝对计量认证；彩色内参、板尺寸/平整度、PnP模型和深度都参与其中。误差接近不应直接相加，也不应据单一位置直接写入-12mm深度补偿。

## 为什么深度一个偏置解释不了全部XY

在本次梨所在像素处，光轴深度每增加1mm，对应base XYZ约变化(-0.432,+0.078,-0.923)mm。若12.324mm差异完全来自深度偏大，其影响约为(-5.32,+0.97,-11.38)mm，XY方向与用户观察的X偏大/Y偏小相反。因此深度误差可能影响Z，但不能据此解释所有XY偏移。

物体完整中心估计仍是独立环节：深度测到可见表面，当前算法用可见点云的XY范围中点估计完整水果中心；斜视和不对称梨的隐藏部分可能引入朝相机方向的偏差。
