你记忆里写"D455 用 25% 百分位计算 centroid z"——这混淆了两件事。深度获取用 5×5 中位数（L677）；25% 百分位出现在 PCA 朝向函数里（L867）估算物体层 z 底部算质心高度，目的是防质心过低撞台面。两者不是一回事。

1.4 像素 → 相机坐标系（针孔反投影）

标准针孔模型反投影（L704-713）：

def monocular_pixel_to_camera_coords(self, u, v, depth):
    x = (u - self.cx) * depth / self.fx
    y = (v - self.cy) * depth / self.fy
    z = depth
    return np.array([x, y, z])

内参来源（两套）：

  • 硬编码 fallback（L124-127）：fx=378.39, fy=379.37, cx=330.14, cy=246.10
  • camera_info 实时覆盖（L289-294 订阅，L781-790 回调）：从 /camera/camera/color/camera_info 取真实内参覆盖。注释（L146-150）说明硬编码与实际差 1.7%，0.5m 处产生 8.5mm 误差。

3.2 核心难点：model.nq=8 但只解 6 个 DOF

URDF 里有 8 个关节（joint1-6 + gripper_joint1/2），但 IK 只解 6 个机械臂关节。所以需要 joint_q_indices（L77-86）记录每个机械臂关节在 8 维配置向量中的起始下标：

# L121: 先取 neutral 8 维向量，再用 6 维 initial_guess 覆盖 joint1-6
q = pin.neutral(self.model)   # 8 维
for i, idx in enumerate(self.joint_q_indices):
    q[idx] = float(initial_guess[i])   # 只填 joint1-6, gripper 保持 neutral

这样 forwardKinematics 收到的 q 长度才匹配 model.nq=8，否则报 "wrong argument size"。

3.3 IK 成功判定（L230-237）——三重安全约束

_, final_pe, final_ze, _ = _combined_error(q)
# final_pe = 位置误差(米)
# final_ze = 末端Z轴与目标Z轴夹角(弧度)
success = bool(final_pe < 0.015 and final_ze < 0.52)
# 0.015m = 15mm 位置阈值
# 0.52rad ≈ 30° Z轴方向约束

危险!] C -- 是 --> Z[✅ IK 成功] style X fill:#4d1a1a,stroke:#f85149 style Y fill:#4d3a1a,stroke:#d29922 style Z fill:#1a4d2e,stroke:#3fb950
为什么需要 Z 轴约束？当物体超出工作空间时，IK 可能返回"位置准但末端朝上"的解——只判位置会接受这种危险解，机械臂会朝上抓。加 final_ze < 0.52 强制拒绝，让 IK 返回失败而非危险解。

3.4 FK 安全检查（L1297-1318）——轨迹终点的硬防线

IK 成功还不够，规划出轨迹后还要用 FK 验证轨迹终点的末端 Z 轴真的朝下：

# L1297-1318
q_full = _pin.neutral(self.ik_solver.model)   # 8 维
for i, idx in enumerate(self.ik_solver.joint_q_indices):
    q_full[idx] = jm.get(f'joint{i}', 0.0)     # 用轨迹终点关节角填 joint1-6
_pin.forwardKinematics(self.ik_solver.model, self.ik_solver.data, q_full)
_pin.updateFramePlacements(self.ik_solver.model, self.ik_solver.data)
ee_z = self.ik_solver.data.oMf[self.ik_solver.ee_frame_id].rotation[:, 2]
if float(ee_z[2]) > -0.5:   # 末端Z轴的z分量 > -0.5 (倾斜>60°) → 拒绝
    self.get_logger().error(f"⛔ 安全拒绝: 轨迹终点末端 Z 轴朝上 ...")
    continue

ee_z = rotation[:, 2] 是旋转矩阵第 3 列（末端 Z 轴方向），ee_z[2] 是它的 z 分量。> -0.5 表示末端 Z 轴与世界上轴夹角 < 60°（朝上或接近水平），直接拒绝该 profile。

4.3 速度是如何控制的

不是手动改 time_from_start，而是通过 MoveIt 的 scaling factor（L684-685, L1270-1271）：

max_velocity_scaling_factor = 0.65      # 最大速度 65%
max_acceleration_scaling_factor = 0.65  # 最大加速度 65%

MoveIt 规划器内部会根据这个因子调整轨迹的 time_from_start 和关节速度。execute_cartesian_path 不设此参数（GetCartesianPath service 不接受），速度由轨迹时间戳决定。
