# Piper 抓取工作台

这是与 Codex 无关的 Ubuntu 原生桌面应用。源码、配置、后台、日志和采集数据均在当前项目内，关闭 Codex 不影响工作台。当前实现保持在独立开发工作树，不自动覆盖主部署目录。

## 打开软件

构建过此工作树后，双击桌面「Piper 抓取工作台」，或从应用菜单打开。终端也可运行：

```bash
./scripts/start_workbench.sh
```

脚本从自身位置定位项目，加载现有 ROS / Orbbec / 本树环境，复用已运行后台。打开窗口不会自动启动 CAN、机械臂、相机或抓取。连接页可分别启动组件，或点击「一键启动全部」补齐未运行项。CAN 使用现有脚本，系统可能显示正常的权限认证窗口；工作台不保存密码。

创建桌面入口：

```bash
./scripts/install_workbench_desktop.sh
```

安装器将执行路径写为运行安装器的项目目录。未来整合到最终部署目录后，在最终目录再运行一次安装器；模板不绑定某个工作树。构建方式沿用 `docs/parallel_development.md`，主要新包为 `piper_workbench`，还需要本树已有机械臂消息、描述、MoveIt、控制与标定包。

## 六个页面

- 抓取：D455 动态、D455 静态、Dabai 静态。两个相机可持续显示及检测，只切换抓取数据来源。D455 静态保留连续与所选单次；Dabai 为所选单次。点击目标框或目标列表选择目标。主页选择统一放置或按原始类别分配。
- 调试：拖动原生末端标记、修改六关节角或输入 TCP 位姿；先「规划」，再「执行」。目标改变后需要重新规划。「读取当前位置」来自实际反馈。抓取参数和手动规划比例分别保存；原动态配置文件继续使用。
- 连接：各组件独立启动、停止、查看日志；一键操作逐项显示结果。机械臂警告提示恢复时，先移开碰撞障碍，再由你点击「碰撞后恢复」。流程重新执行原 CAN、激活和 T1 启动，结束后保持暂停；相机、YOLO、T5 保留。对于外部终端启动且不在当前工作树登记的旧 T1，请在原终端停止后再恢复，避免误停其他会话。
- 标定：内参、手眼、TCP 沿用近期现场工具，按钮写入原程序的 Enter / d / q / c；输出、质量和误差原文保留。手眼验证打开真实 RViz TF。TCP sweep 可选轴、角度、步数、速度和规划／执行，执行前界面提示腾出活动空间。
- 图片采集：保存订阅到的新原始彩色帧，可选一台或两台，单张或默认每 2 秒定时，保存 PNG 和来源清单，可导出 ZIP。无框、无标签、无训练；两台的时间戳独立记录。
- 日志：汇聚后台、启动器、组件、ROS 和标定 PTY 输出，按来源／时间／级别／关键词筛选，详情保留多行与 traceback；界面最近 10000 条，磁盘历史可导出或打开。动态诊断从现有报告读取误差、TCP 高度和夹爪曲线，缺失字段显示无数据。

## 示教与放置

通过机械臂实体按钮进入示教模式；摆到希望的位置后，点击读取或保存点。界面每次保存点会重新读取新鲜的 `/feedback/joint_states`，保存本身不运动。每个方案有稳定 ID、可改的名称、0～5 个途经点和释放点。待机与 Dabai 观察位也可从实际关节反馈保存。

方案在每个物体开始时固定，编辑只影响后续物体。D455 静态释放后回保存的待机位；Dabai 静态回保存的观察位；动态沿用现有拦截区准备位。急停、失败和碰撞恢复不附加正常返程。

## 标定文件与生效状态

在调试的「标定文件」选择相机与类型，导入／查看原文／应用选中。候选原文件保持原样，活动副本、manifest 和上个版本备份保存在本项目。用户主动选用不会被包装成 `passed` 或 `scene_verified`。

应用后先显示等待重载。内参核对检测器实际加载的 K/D；手眼核对检测器参数及实际 TF；TCP 核对 SDK 启动参数、驱动在线参数、MoveIt 模型和工作台模型。实际数值一致才显示已生效；没有组件反馈就保持等待，不影响无关操作。TCP 需要重启 T1 / MoveIt 并重开窗口加载新模型。原始误差和现场精度仍需你按原验证流程检查。

## 窗口、后台和恢复

关窗或意外断连请求“当前一个物体完成后暂停”，任务按原流程停带；已有机械臂、相机、YOLO 和动作节点继续运行。重新打开只恢复界面连接，不自动续抓。后台 socket 为 `.runtime/workbench.sock`，日志在 `log/workbench`。

精确的 `Agx_arm is not connected, cannot control` 警告来自当前 T1 实例时，工作台累计次数并提示重新连接；历史实例不触发新警告。这能提示连接异常，不能单凭这一行断定发生了碰撞。恢复取消旧动作和待派发队列，不发回零或松爪指令。

## 平板上位机

“调试 → 平板上位机”管理 HTTPS 网关、媒体服务、一次性配对码、在线设备、控制租约、视频健康和本地 CA。平板进程与电脑工作台相互独立，启动失败不会中断现有抓取流程。安装、配对、证书、接口和平板功能说明见 [../tablet_hmi.md](../tablet_hmi.md)。
