# Piper 平板便携操作终端设计 v0.3

> 日期：2026-10-19  
> 版本：v0.3  
> 目标设备：iPad 优先，Android 平板兼容  
> 部署范围：实验室同一局域网  
> 设计基线：与电脑端 Piper 工作台保持统一视觉语言  
> 新增能力：电脑调试页“平板上位机”管理页
> 核心媒体：WebRTC H.264，WebSocket JPEG 降级
> 三维方案：电脑端 FK 下发布信矩阵，iPad Three.js 渲染

## 1. 版本目标

本版在 v0.2 的控制网关、低延迟视频和服务端 FK 基础上，补充三点：

1. 平板前端与电脑工作台使用同一套视觉规范。
2. 增加有节奏、可降级的动效体系。
3. 在电脑工作台“调试”页新增“平板上位机”管理页。

平板仍是便携 HMI，电脑端仍是唯一控制与视觉服务器。

## 2. 范围

### 2.1 平板范围

平板包含两个主页面：

1. 抓取：双相机、检测目标、机械臂三维模型、抓取流程、模式、放置点和抓取操作。
2. 连接：设备状态、组件启停、CAN、机械臂激活、碰撞恢复、一键启动与关闭。

### 2.2 电脑端新增范围

在现有“调试”页增加一个子页：

```text
运动调试 | 抓取参数 | 相机与检测 | 动态分界与区域 | 标定文件 | 示教与放置点 | 平板上位机 | 高级
```

管理页负责：

- 网关与媒体服务状态。
- 平板配对二维码。
- 在线设备和访问权限。
- 控制租约。
- 视频流健康状态。
- 本地证书与 PWA 版本。
- 网关和媒体服务启停。
- 设备撤销和媒体重启。

### 2.3 不纳入

- 平板运行 ROS 2、MoveIt 或 YOLO。
- 平板拖动机械臂规划。
- 完整 RViz。
- 参数编辑、示教、标定、图片采集和完整日志分析。
- 公网远程访问。

```text

┌───────────────▼─────────────────┐  ┌─────────▼────────────────┐
│ workbench-gateway               │  │ workbench-media          │
│ 鉴权、快照、事件、操作          │  │ GStreamer H.264          │
```

### 3.1 控制平面

`workbench-gateway`：

- PWA 静态资源。
- 配对、会话、设备令牌。
- snapshot 和增量事件。
- 白名单命令。
- 控制租约。
- 机械臂 link 位姿。
- 平板管理状态。
- 媒体令牌。

### 3.2 媒体平面

`workbench-media`：

- 订阅 ROS 图像。
- 硬件 H.264 编码。
- WebRTC/WHEP。
- JPEG 降级。
- 流健康统计。

媒体服务异常不能影响控制网关、机械臂任务和电脑本地工作台。

### 3.3 权威状态

`workbench-service` 是设备、组件和任务状态的唯一权威。

平板与电脑管理页显示的数据都来自同一后端状态，不做前端推断式“成功”。

## 4. 进程和启动

新增进程：

| 进程 | 职责 |
|---|---|
| `workbench-gateway` | 页面、鉴权、状态、操作、租约、管理 |
| `workbench-media` | H.264、WebRTC、JPEG 降级 |

启动顺序：

1. `workbench-service`。
2. `workbench-gateway`。
3. `workbench-media`。
4. iPad 连接。

电脑工作台“平板上位机”页可分别启动、停止和重启网关与媒体服务。

网关退出只影响平板，不影响 T1、T5、相机和电脑本地工作台。

## 6. 动效系统

### 6.1 时间与缓动

```css
--motion-fast: 120ms;
--motion-base: 180ms;
--motion-slow: 240ms;
--motion-flow: 420ms;
--ease-standard: cubic-bezier(.2, .8, .2, 1);
--ease-emphasis: cubic-bezier(.16, 1, .3, 1);
```

### 6.2 页面和模式

- 页面切换：内容淡入 + 8 px 位移，180 ms。
- 左侧导航：蓝色指示条滑动，190 ms。
- 模式切换：一个共享高亮底块滑动，内容淡入，不逐个按钮跳动。
- 连接页 Tab：底部蓝线滑动。

### 6.3 按钮

- Hover：背景和边框渐变，120 ms。
- Press：缩放 0.98，表面高光闪动，140 ms。
- Pending：变灰、显示“启动中/应用中”，可加 16 px 旋转环。
- Success：文字变为“已启动/已应用”，绿色勾选 Morph，保持 1.2 s。
- Failure：按钮恢复，红色描边抖动一次，并显示错误。

### 6.4 抓取流程

- 当前节点：向外呼吸的蓝色光晕。
- 阶段切换：进度轨道平滑推进，420 ms。
- 已完成节点：白色勾选。
- 异常节点：砖红色。
- 完成后保留 1.6 s，再回到等待状态。
- 页面隐藏时暂停呼吸动画。

### 6.5 相机和目标

- 当前相机切换：卡片交叉淡入。
- 目标选中：框线扩散一次，列表行同步高亮。
- 视频断流：最后画面保留，顶部出现“已暂停 N 秒”。
- 重新取流：状态灯从琥珀过渡到绿色。

### 6.6 机械臂

- 服务端位姿到达后做位置 lerp 和四元数 slerp。
- TCP 点移动时带轻微渐隐尾迹。
- 模型切到目标影子时使用 200 ms 透明过渡。
- 断连时只降低模型饱和度和显示警告，不隐藏模型。

### 6.7 动效预算

- 同一屏最多一个持续循环主动画。
- 页面隐藏、切后台或低性能模式时暂停循环和模型渲染。
- 动画优先 `transform` 和 `opacity`。
- 不在大面积区域持续使用 `filter`、`backdrop-filter` 和阴影扩散。

## 10. 视频设计

### 10.1 主链路

```text
ROS Image
   ↓
GStreamer appsrc
   ↓
NVENC/VAAPI H.264
   ↓
MediaMTX / go2rtc
   ↓
WHEP
   ↓
iPad Safari <video>
```

- H.264 Main Profile。
- 640×480。
- D455 15～30 fps。
- Dabai 12～15 fps。
- 目标总码率 3～5 Mbps。
- 检测框在 Canvas 叠加，不烧录视频。

### 10.2 降级

WebRTC 失败后：

- WebSocket JPEG。
- 当前可见相机 5～8 fps。
- 另一相机暂停。
- 页面显示“低带宽模式”。

### 10.3 背压

- 每路只保留最新帧。
- 编码队列上限 2。
- 页面隐藏时暂停编码。
- 恢复可见后新建 WebRTC。
- 不累积旧帧。

```text
robot.glb
model_manifest.json
```

- 每个 link 网格位于局部原点。
- glTF 2.0。
- Meshopt 压缩。
- 不包含碰撞体和惯性。
- 目标资源 5～8 MB。
- PWA 首次下载后缓存。

### 11.2 电脑端 FK

电脑端查询：

```text
base_link -> link1
base_link -> link2
...
base_link -> tcp_link
```

发送：

```json
{
  "type": "robot_link_poses",
  "stamp": 1792385000.123,
  "links": {
    "link1": [x, y, z, qx, qy, qz, qw]
  }
}
```

使用位置+四元数，不发送完整 4×4 矩阵。频率 15～20 Hz。

### 11.3 平板渲染

- Three.js WebGL2。
- 平移 lerp 和四元数 slerp。
- DPR 上限 2。
- 关闭阴影。
- 隐藏时停止渲染。
- 低性能时降低到 15 fps。
- 支持高/中/低 LOD。

### 11.4 完整 RViz

仍在电脑端使用。需要平板查看时，通过按需 WebRTC/远程桌面共享 RViz 窗口。

## 13. 安全

### 13.1 配对

```text
https://piper.local:8443/pair?code=<one-time-code>
```

- 一次性码默认 10 分钟。
- 换取 HttpOnly、Secure、SameSite Cookie。
- 电脑管理页可撤销设备和全部配对。
- 连续失败触发退避。

### 13.2 媒体令牌

- 60 秒短期令牌。
- 只允许对应设备与相机。
- WHEP 建连前验证。
- 长期令牌不传给媒体服务。

### 13.3 权限

| 角色 | 权限 |
|---|---|
| 观察者 | 状态、相机、模型、流程 |
| 操作者 | 观察权限 + 抓取和连接操作 |
| 电脑本地工作台 | 全部权限，可收回租约 |

### 13.4 sudo

- sudo 密码只存在电脑本地。
- 平板和管理页都不显示密码。
- 网关不记录密码。

## 14. 控制租约

- 同一时刻只有一个平板持有操作租约。
- 默认为 15 秒，每 5 秒续约。
- iPad 后台超时后释放。
- 电脑本地可立即收回。
- 无租约时平板只读。
- 管理页显示剩余租约时间和设备。

## 15. 断线恢复

- WebSocket 指数退避重连。
- 恢复后拉 snapshot。
- 已开始动作继续。
- 连续任务暂停后续派发。
- 租约丢失不触发回零或松爪。
- 媒体断流只影响画面。
- 网关退出不影响本地工作台。
- 网关重启后 PWA 自动重连。
- PWA 更新不在动作中强制刷新。

## 17. 性能档位

| 项目 | 高 | 标准 | 低 |
|---|---:|---:|---:|
| D455 | 30 fps | 15 fps | 8 fps |
| Dabai | 15 fps | 10 fps | 冻结非当前流 |
| 模型 | 30～60 fps | 30 fps | 15 fps |
| DPR | 2 | 1.5 | 1 |
| 检测框 | 10 Hz | 5 Hz | 3 Hz |

触发降级：

- 连续掉帧超过 1 秒。
- 视频队列持续积压。
- WebRTC 重建频繁。
- 页面长时间隐藏后恢复。
- 用户手动选择“低功耗”。

## 18. 错误隔离

- 相机、模型、流程、连接、日志分别有错误边界。
- Three.js 失败只隐藏模型。
- WebRTC 失败切换到 JPEG。
- WebSocket 丢失不影响已开始任务。
- 网关/媒体独立进程。
- 平板崩溃不影响电脑工作台。
- 管理页操作失败显示具体组件和原因。

## 22. 风险

- WebRTC 和媒体服务增加部署复杂度，使用成熟组件。
- iPad 本地证书需要一次性信任。
- Safari 后台会暂停页面，控制租约必须服务端管理。
- 视频、3D 和动画共享 GPU，需要性能档位。
- GLB 网格过大，需要 LOD 和 Meshopt。
- 多人操作产生竞争，需要控制租约。
- 管理页不能成为第二套状态源，必须读取网关和服务端真实数据。
